# Lab 08 – Object Relationships in Java

## Project Details
- **Project:** Lab08_ObjectRelationships_Student
- **Package:** `com.uet.construction.fleetops`
- **Language:** Java
- **Build Tool:** Maven

## Tasks
- **Aggregation:** Implemented Driver–Vehicle and Depot–Vehicle relationships with independent lifecycles.
- **Composition:** Vehicle owns its Engine and MaintenanceLog objects.
- **Defensive Copying:** Prevented external modification of internal Engine and maintenance history.
- **Verification:** Created `FleetVerificationDriver` to test object relationships and encapsulation.

## How to Run
1. Open the project in NetBeans.
2. Run `FleetVerificationDriver.java`.
3. Check the console for `[PASS]` verification results.

## Conclusion
This lab demonstrates Aggregation, Composition, lifecycle independence, and defensive copying in Java using a Fleet Management System.
